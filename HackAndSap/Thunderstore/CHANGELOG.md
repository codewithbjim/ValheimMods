# Changelog

## 0.1.0

- Added adjacent Use-key cutting interactions for discovered fellable trees and
  felled logs.
- Added repeated equipped-axe attacks using vanilla stamina, durability, Wood
  Cutting skill, damage, effects, drops, and persistent target health.
- Added runtime support for all trees using Valheim's standard log-producing
  pipeline, including Ancient, mature Yggdrasil, and Ash trees.
- Added owner-authoritative stump-to-sapling renewal using the exact source-tree
  identity.
- Added inactivity-based decay that removes abandoned logs without drops.
- Added configurable player-base protection and synchronized gameplay settings.
